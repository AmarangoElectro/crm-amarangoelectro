# CRM AmarangoElectro

Versión simplificada:

- Cobranzas en formato planilla con una fila por cuota.
- Casilla para registrar o quitar un pago sin salir de la planilla.
- Columnas: cliente, producto, número de cuota, monto y fecha a abonar.
- Totales pendientes y vencidos separados.
- Facturación total y ganancia real separadas en Ventas.
- Acceso limitado a las cuentas de Maxi y Angie.
